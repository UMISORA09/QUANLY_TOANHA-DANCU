# Quy tắc Commit Message / Commit Message Rules

Luôn viết commit message bằng **cả tiếng Việt và tiếng Anh**, theo format:

```
<type>: <Tiếng Việt> / <English>
```

## Ví dụ / Examples

- `feat: Khởi tạo cấu trúc dự án Laravel / Init Laravel project structure`
- `fix: Sửa lỗi đăng nhập / Fix login bug`
- `docs: Cập nhật tài liệu API / Update API documentation`
- `refactor: Tái cấu trúc controller / Refactor controller`
